# 7 UI audit

- The web viewport keeps pinch-zoom enabled so users can enlarge text and controls.
- Shared fields expose their labels to assistive technology, shared buttons expose disabled state, and password visibility/mode controls are named.
- Receipt capture sheets are scrollable and capped to the viewport so camera and gallery actions remain reachable on short screens.
- A scanned purchase document stays local while extraction is reviewed. It is uploaded only after the user saves the purchase, avoiding abandoned private files when review is cancelled.
- The workspace menu captures touches inside its card so selecting an item does not also trigger the dismiss overlay.
